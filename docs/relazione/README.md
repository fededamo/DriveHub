## Compilazione

Per il pacchetto finale è verificato **XeLaTeX, TeX Live 2025/Debian**:
seguire i tre passaggi nelle [istruzioni di consegna](LEGGIMI-consegna.md).
La compilazione non richiede il repository applicativo né contenuti editoriali
in `/tmp`. La prova nell'ambiente temporaneo, i prerequisiti e i limiti sono
registrati nelle [verifiche 13](verifiche/ticket-13/README.md), con nuova
estrazione e ricompilazione del pacchetto corrente; motore e risorse LaTeX
restano prerequisiti esterni. Le verifiche 08 attestano il loro pacchetto storico.

Procedura storica Tectonic usata nei ticket 01–07, non rieseguita nel 13:

Eseguire dalla directory `docs/relazione`. Con **Tectonic 0.17.0**, che gestisce
automaticamente i passaggi necessari per indice e riferimenti:

```bash
mkdir -p build
tectonic --untrusted --keep-intermediates --keep-logs --outdir build main.tex
cp build/main.pdf relazione-drivehub.pdf
```

La prima compilazione richiede Internet per scaricare le risorse LaTeX.
Il ticket 07 ricontrolla Tectonic 0.17.0 GNU e PyMuPDF già disponibili
nell'ambiente temporaneo del ticket 06; versioni, impronte e
comandi effettivi sono nelle [verifiche](verifiche/ticket-07/README.md).
Il pacchetto LaTeX `listings`, usato nei capitoli 3–4, è stato
recuperato nella cache. I frammenti sono incorporati nel LaTeX e
confrontati con gli intervalli dei Java correnti: la compilazione non
richiede file di contenuto in `/tmp`. Gli eseguibili e le cache temporanee
non sono prerequisiti garantiti su un altro PC: occorre fornire Tectonic
oppure un ambiente LaTeX compatibile.
Il PDF distribuito non richiede tali strumenti per
essere aperto.

I sorgenti usano pacchetti LaTeX comuni (`babel` con italiano, `geometry`,
`graphicx`, `pdfpages`, `enumitem`, `xcolor`, `listings`, `longtable`, `array`, `hyperref`) e mantengono le convenzioni di
`Relazione_SWE/main.tex`: classe `report`, A4, corpo 12 pt, margini di 2,5 cm,
frontespizio, indice in numeri romani e capitoli in numeri arabi. Il ramo per
`pdfminorversion` è condizionale per consentire anche il motore di Tectonic.
Il ticket 13 verifica la distribuzione XeLaTeX sopra indicata sul pacchetto corrente;
identità binaria fra motori e funzionamento Windows/macOS non sono garantiti.

stesura, senza riproporre come correnti classi o meccanismi rimossi.
