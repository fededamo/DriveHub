# Etichette di triage

Vocabolario standard delle skill per il campo `Status:` dei ticket Markdown locali. Queste etichette non sostituiscono avanzamento e criteri di chiusura.

| Ruolo della skill | Etichetta nel tracker | Significato |
|---|---|---|
| needs-triage | needs-triage | Segnalazione da valutare. |
| needs-info | needs-info | Mancano informazioni necessarie. |
| ready-for-agent | ready-for-agent | Specifica sufficiente per il lavoro di un agente; controllare comunque le dipendenze. |
| ready-for-human | ready-for-human | Richiede un intervento umano. |
| wontfix | wontfix | Non verrà implementato. |

Nessuna etichetta viene creata su GitHub o altri servizi: il tracker è locale.
